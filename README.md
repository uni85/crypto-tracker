# 🪙 CryptoLive Tap: Vanilla JS Market Tracker

A real-time cryptocurrency price tracker built with **Vanilla JavaScript**, utilizing the CoinGecko API. This project focuses on high-performance DOM manipulation, asynchronous data fetching, and responsive CSS Grid design.

## 🛠 Features
* **Real-Time Updates:** Market data automatically refreshes every 60 seconds without page reloads.
* **Live Search:** Instant filtering of coins by name or symbol using an optimized event listener.
* **Dynamic UI:** Custom-built cards that change color (Green/Red) based on 24-hour price trends.
* **Error Handling:** Graceful degradation and user notifications if API limits are reached.
* **Responsive Design:** Fully mobile-responsive layout using CSS Grid and Glassmorphism.

## 🧰 Tech Stack
* **HTML5:** Semantic structure for accessibility.
* **CSS3:** Custom properties (variables), Flexbox, and CSS Grid.
* **JavaScript (ES6+):** Fetch API, Async/Await, DOM manipulation, and Intervals.

## 📖 Lessons Learned
Building this project helped me master several core concepts:
1.  **Asynchronous Logic:** Managing the lifecycle of a Promise and handling potential network failures.
2.  **State Management:** Keeping the UI in sync with the data retrieved from the API.
3.  **Performance:** Efficiently filtering DOM elements during search without re-triggering expensive API calls.
